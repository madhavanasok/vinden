# Vinden

Design work for Vinden, a proof-of-work professional network for students and early-career professionals (18–30).

## Contents

- `design/app-screens/` — mobile app core screens (Home, Proof of Work, Profile), styled after the Tripadvisor iOS app and using the approved Vinden palette.
  - `Main.dc.html` — Home
  - `PowDetail.dc.html` — Proof of Work detail
  - `Profile.dc.html` — Profile
  - `canvas.json` — canvas layout

The `.dc.html` files are the source of a Claude Design canvas. They need the canvas runtime (`support.js`), so they don't open directly in a browser. View them on the canvas: https://claude.ai/artifact/ThUjju4nKmcXNww3o9xVja (private until shared).
